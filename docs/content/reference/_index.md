# Reference

These pages describe every field and every behavior. They do not build a setup step by step; the [tutorials](@/tutorials/_index.md) do.

- [Configuration and Storage](@/reference/storage.md): the config directory, backups and disaster recovery.
- [Ports](@/reference/ports.md): listening ports, TLS, PROXY protocol, port ranges and transparent mode.
- [Proxies](@/reference/proxies.md): routing, load balancing, security, caching and every other proxy option.
- [Certificates and ACME](@/reference/certificates.md): certificates, ACME, DNS credentials and CT monitoring.
- [Service Discovery](@/reference/discovery.md): proxies from Docker labels and etcd keys.
- [Deployment Platform](@/reference/platform.md): apps, databases, backups and agent targets.
- [Accounts](@/reference/accounts.md): roles, proxy lists and API tokens.
- [Host Firewall](@/reference/firewall.md): the nftables table of the host.
- [Server Operation](@/reference/server.md): workers, upgrades, HTTP limits, stream priority and metrics.
- [MCP and CLI](@/reference/mcp-and-cli.md): the MCP server, its tools and the `r3` client.
- [Administration](@/reference/administration.md): settings, the WebUI, the admin API, the audit log and logging.
- [Release Verification](@/reference/release-verification.md): checking the signature of a release.
- [Development](@/reference/development.md): building and testing r3v3rs3.
